# 第11次改修：お気に入り・番組一覧UI
VICTORY K / 2026-10-27 / Android 0.3.0 (versionCode 3)

## 完了内容
既存0.2.0のAndroidプロジェクトを継続改修。主な機能差分はMainActivity.kt、Browse.ktの追加とバージョン更新、FavoritesTest.ktの追加。従来リポジトリにはAndroid本体が未配置だったため、既存ビルド済みプロジェクトからandroid/へソース一式を保存した。作り直しではない。
- 「☆番組」を「☆この回」、「☆シリーズ」を「☆毎回チェック」へ変更。登録時は★と色、読み上げ用の登録状態で区別。
- お気に入りではジャンル設定を適用せず、選択した今日／明日／1週間だけを適用。放送開始前の枠を日本時間・日時順にまとめ、同じ枠を重複表示しない。
- 期間内に枠がない登録者には「お気に入り登録済みですが、期間内の放送予定はありません」。未登録者の案内と分離。
- 新しい放送回が同じシリーズIDで追加されると、既存s:キーで自動的にお気に入り対象になる。
- 単発作品と放送枠由来のシリーズIDでは毎回チェックを隠す。映画を一律に除外せず、現行のゴジラ作品群・ダイ・ハード作品群は既存シリーズIDの性質に従い継続登録を残した。未知の映画枠や作品群を勝手に新IDへ変換しない。
- 旧版で単発作品をシリーズ保存していた場合もデータを維持し、お気に入りへ表示。カードの「★ 登録を解除」で旧登録を解除できる。
- カードは時刻・局・タイトル・ジャンル・お気に入り操作に整理。濃紺／ゴールド／紫を維持。長いタイトルを省略せず、操作ボタンは48dp以上、狭い幅では折り返す。
- 確認状況バナーと「再放送（確認済み）」の表示を撤去。番組説明・出演者・画像・出典はカードへ表示しない。通信失敗、一部更新失敗、データ期限切れの警告と最終更新時刻は残す。
- 設定の「情報提供元」にしょぼいカレンダー等のクレジットとリンクを集約。

## 実機で確認する手順
1. 旧版を消さず新APKを上書きし、既存のお気に入りと設定が残ることを確認。
2. 心霊・怪談の番組を「この回」で登録後、映画だけをONにして「お気に入り」を開く。期間を1週間にすると心霊の登録枠も表示されることを確認。
3. 「毎回チェック」で登録・解除し、同じシリーズIDの他の回も一覧へ反映されることを確認。
4. 単発映画では毎回チェックがなく、ゴジラ作品群などは継続操作を表示することを確認。
5. 今日／明日／1週間、アプリ終了と再起動、データ更新、機内モードを順に確認。登録が残り、期間内に枠がない場合の文言が適切であることを確認。
6. 大きい文字設定と狭い画面で長いタイトル・ボタンの折返し、設定の情報提供元リンクを確認。
7. 通知OFFのまま☆登録して通知がONにならないことを確認。
