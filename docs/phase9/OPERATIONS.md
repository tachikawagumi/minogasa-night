# 第9次：番組表の個別調査による追加
今回は新たな検索機構を作らず、既存のdata/manual-approved.jsonと公開処理を使用した。
ユーザーの番組表調査・掲載指示に基づき、個別に確認した12枠を追加、掲載済み1枠の終了時刻を更新する。
第三者番組表の確認はstatus=provider_confirmed、officialVerified=false。公式確認と誤記しない。
出典URL・確認日時・分類根拠・個別の利用判断は当該レコード、data/source-checks.json、config/source-policy.jsonへ記録。
サイトの番組表全体や紹介文・画像を保存・転載せず、公開JSONは既存スキーマ1の最小項目だけ。
台帳が第三者確認済みの日時を正しく保持できるようscheduleVerificationを追加し、公式確認とは分けた。既存の提供元確認済みステータスを再利用する。
GitHub ActionsとPagesへの公開経路、しょぼいカレンダー、既存APK、お気に入りID、20ジャンルを維持。
Gガイドは規約の再提供/類似サービス利用の制限を確認したため、今回の掲載供給元として使用していない。
sf-dreamの一般公開ページは個別参照し、確認範囲で最小事実の独立記録に関する固有の制限は見つからなかった。包括的な再配信や継続クローラーの許可を得たという意味ではない。
NHK BSは全国放送。参照可能だった340（広島）地域ページのNHK BS欄を使い、東京地域のNHK総合と取り違えない。日付境界は放送日表記と暦日を区別する。
10/28の00:45欄は10/29 00:45、TBS 11/1深夜1:13は公式表の実日時202611020113で11/2 01:13と照合した。
今後の訂正・中止も確認できた事実に従い同じIDで更新。古い放送を未来へ移さない。
承認操作をユーザーが実際に何回押したかは計測できないため、ゼロと断定しない。一括読取・編集・テスト・反映を優先し、必要なシステムの確認は遵守する。
