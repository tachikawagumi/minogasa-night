# みのがさナイト：チャッピー主担当の調査・掲載運用

**2026-11-09改訂。** 対象：東京・千葉で受信対象の地上波と無料BS、現在から7日先（JST）。20ジャンル、Android、しょぼいカレンダーAPI、公開URLとJSONスキーマは維持。

## 1. 調査先を固定する（ユーザー指定・最優先）

| 調査対象 | 通常の調査先 | 説明 |
|---|---|---|
| 一般ジャンル（映画、ディズニー、釣り、車、旅、大食い、ホラー映画等） | **Gガイド** https://bangumi.org/ と **J:COM番組表** https://tvguide.myjcom.jp/ | 2サイトの個別番組表から番組名・局・放送日時・当該回の内容を探す。放送局公式サイトでの再照合は原則不要 |
| アニメ | **しょぼいカレンダー** https://cal.syoboi.jp/ | 既存のAPI取得・フィード構築を維持。その他の番組表でアニメ全件を改めて採録しない |
| 心霊・怪談、UFO・都市伝説 | **オカルト番組表** https://www.occultic.net/occulttv.html | 最初にこのサイトを探し、必要な局・日時の補足のみGガイド・J:COMを使う。アクセス制限を回避せず検索エンジンの公開索引を代替利用してよい |

**それ以外の多数の公式局サイト・専門サイトを毎回巡回しない。** 古い `config/discovery.json` の `sourceCatalog` URLは履歴互換のため残るが、通常の検索に利用しない。参照先を絞って見落としを防ぐのが今回の目的。

## 2. 発見優先のキーワード

- 釣り：**「釣」「マグロ」「漁」「魚」** をそれぞれ番組表検索。魚料理、市場、漁港、漁師、魚の短い特集も `fishing` に含めてよい。
- ディズニー：**「ディズニー」「TDL」「TDS」** をそれぞれ検索。作品、東京ディズニーランド/シー、ホテル・グルメ、バラエティ内特集も `disney` に含む。
- 映画：午後のロードショー、金曜ロードショー、サタ☆シネ、BS映画、永野映画CHANNEL、早朝・深夜枠も探す。ホラー映画・ディズニー映画など複数ジャンル可。
- 心霊・UFO：定番オカルト番組だけでなく、バラエティの一部オカルト特集や再放送も対象。番組名だけでなく当該回の内容でジャンルを判定。

## 3. 番組登録

1. Gガイド・J:COM・オカルト番組表等で**番組名・放送局・放送日・開始時刻**の個別放送事実が確認できれば候補。公式サイトの追加照合を必須にしない。日付・時刻・局を推測で埋めない。深夜27:05は翌03:05。
2. `tachikawagumi/minogasa-night` の `main` で `data/manual-approved.json` と `public/v1/programs.json` を読み、既存IDと同一放送枠の重複を排除する。既存行を大量削除しない。
3. `records` に追加。時刻はJSTオフセット付きISO 8601、終了時刻が不明ならnull。一般番組表からの個別事実は `status:"provider_confirmed"`、実際に局公式情報を確認した場合だけ `status:"official_confirmed"`、`publicationApproved:true`、`sourceUrl`は実際に参照した個別番組表URL。出典と独自の短い分類根拠を残す。
4. 最新blob SHAを用いてGitHubにcommit。公開用 `public/v1/programs.json` は直接編集しない。GitHub Actions `scripts/autopublish.py` がアニメと承認済み番組を統合して公開する。
5. GitHub登録後に公開URL https://tachikawagumi.github.io/minogasa-night/v1/programs.json を確認し、**「調査した」「GitHubへ登録した」「本番へ掲載した」**の3段階を区別して報告する。

番組表の本文・画像・編成全体は転載しない。大量アクセスやアクセス制限回避は禁止。対象外局、有料BS/CS、配信のみ、放送日時が不明な番組は公開しない。

## 4. 予約タスク

- 月曜・木曜 07:00：心霊・UFO専門（オカルト番組表を優先、GitHubには書かない）。
- 月曜・木曜 07:20：映画専門（Gガイド・J:COMのみ、GitHubには書かない）。
- 月曜・木曜 09:00：統括チャッピー（20ジャンル、調査の統合・GitHub登録）。
- 日曜：週間オカルト・週間映画の既存通知は同じ情報源ポリシーを適用。

専門チャットの結果を統括が必ず参照できるとは限らない。取得できない場合は正直に報告し、指定サイトで自主調査する。

## 5. 現状と残課題

既存のしょぼいカレンダー経路はアニメを自動配信できる。一方、非アニメはChatGPTによる個別番組発見・GitHub登録に依存する。定期タスクによるGitHub書込実績はあるが、**専門タスク間の結果の自動引き継ぎは未解決**。番組表検索の網羅性も未保証なので、ジャンル別の取りこぼしを継続的に点検する。
